## Problem Statement

This project develops a machine learning predictive framework for child malnutrition risk among children under five in Kenya, using the **2022 Kenya Demographic and Health Survey (KDHS)**. Three binary outcomes are predicted:

- **Stunting** (HAZ < −2 SD) — chronic undernutrition
- **Wasting** (WHZ < −2 SD) — acute undernutrition  
- **Underweight** (WAZ < −2 SD) — combined

SHAP values are aggregated per county to generate county-level risk intelligence for all 47 Kenyan counties, directly supporting devolved health planning.

## Setup & Reproduction

### Prerequisites
- Python 3.11+
- Docker & Docker Compose (for deployment)
- 2022 KDHS Children's Recode file: `KEKR8CFL.DTA`

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the data pipeline
```bash
python 01_pipeline.py --kr_path /path/to/KEKR8CFL.DTA
```
Outputs: `data/features_train.csv`, `data/features_test.csv`, `data/processed_full.csv`

### 3. Train models
```bash
python 02_train.py              # train all three outcomes
python 02_train.py --outcome stunted   # single outcome
```
Outputs: `models/best_model_*.pkl`, `models/results_summary.csv`, `models/shap_values_*.csv`

### 4. Run the API locally
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
API docs: http://localhost:8000/docs

### 5. Run with Docker
```bash
docker-compose up --build
```
API available at: http://localhost:8000

## API Usage

### Health check
```bash
curl http://localhost:8000/health
```

### Single prediction
```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "child_age_months": 24, "child_sex": 1, "birth_order": 2,
    "prev_birth_interval": 30, "size_at_birth": 3,
    "birth_weight_kg": 3.1, "diarrhea_2wk": 0, "fever_2wk": 1,
    "breastfeeding": 1, "maternal_edu": 1, "maternal_bmi": 22.5,
    "wealth_index": 2, "under5_in_hh": 3, "hh_head_sex": 1,
    "hh_head_age": 35, "electricity": 0, "residence_urban": 0,
    "wash_score": 1, "county": 23
  }'
```

> **Field encoding:** `child_sex` and `hh_head_sex`: 1 = male, 2 = female.  
> `breastfeeding`: 1 = currently, 2 = previously, 3 = never.  
> `wealth_index`: 1 = poorest → 5 = richest.

### Response
```json
{
  "predictions": {
    "stunted":     {"probability": 0.6821, "flag": true},
    "wasted":      {"probability": 0.1234, "flag": false},
    "underweight": {"probability": 0.4512, "flag": false}
  },
  "county": 23,
  "model_version": "1.0.0"
}
```

## Modelling Approach

| Component | Choice | Justification |
|---|---|---|
| Baseline | Logistic Regression | Directly comparable to prior Kenya regression studies |
| Ensemble baseline | Random Forest (200 trees) | Handles non-linearity; robust to class imbalance |
| Primary candidate | XGBoost | Sequential boosting; strongest on tabular DHS data in prior SSA studies |
| Class imbalance | SMOTE (training only) | Prevents synthetic samples leaking into test evaluation |
| Validation | 5-fold stratified CV | Preferred over hold-out at ~8k training rows |
| Primary metric | AUC-ROC | Threshold-independent; appropriate for imbalanced outcomes |
| Co-primary metric | Recall | Missing a malnourished child carries greater cost than a false alert |
| Explainability | SHAP TreeExplainer | County-level feature importance aggregation — methodological novelty |

## Data Source

**2022 Kenya Demographic and Health Survey (KDHS)**  
- Conducted August 2022 – February 2023  
- Stratified two-stage cluster design; nationally representative across all 47 counties  
- Children's Recode (KR file): ~8,099 children under 5 with valid anthropometric records  
- Access: https://dhsprogram.com (free for non-commercial research)
